Seja Alpha — computador (Windows)

Cria o atalho na área de trabalho, com a logo da empresa, abrindo o sistema em janela limpa. Não instala programa nenhum e não precisa ser administrador.

Baixar
  1. Baixe o arquivo, clique com o botão direito → Extrair tudo.
  2. Dê dois cliques em Instalar Seja Alpha.
  3. O ícone aparece na área de trabalho. Este link é montado na hora, então sempre traz a versão atual.

Seja Alpha — celular e tablet

Não existe arquivo para baixar aqui, e é de propósito: o próprio site é o app. Ele se instala pelo navegador, com ícone na tela de início, abrindo em tela cheia, sem barra de endereço — igual a um aplicativo de loja. Vantagem: atualiza sozinho, sem ninguém precisar reinstalar nada quando o sistema muda.

🤖 Android — celular

  1. Abra whatts.alphafitus.com.br no Chrome.
  2. Toque em ⋮ (canto superior direito).
  3. Escolha Instalar app ou Adicionar à tela inicial.
  4. Confirme. O ícone aparece junto dos outros apps.

🍎 iPhone

  1. Abra o endereço no Safari (no iPhone só funciona pelo Safari).
  2. Toque no botão Compartilhar (quadrado com seta pra cima).
  3. Role e escolha Adicionar à Tela de Início.
  4. Toque em Adicionar.

📋 Tablet Android

  1. Mesmo caminho do celular Android, pelo Chrome.
  2. A tela se reorganiza sozinha pro tamanho maior: lista de conversas e conversa aberta lado a lado.

📋 iPad

  1. Mesmo caminho do iPhone, pelo Safari.
  2. Compartilhar → Adicionar à Tela de Início.

📦 Android — instalar pelo arquivo (APK)

Alternativa ao caminho pelo navegador, para quem prefere um arquivo para instalar. O app abre em tela cheia e continua se atualizando sozinho — o conteúdo vem do site, então não é preciso reinstalar a cada mudança do sistema.

⬇ Baixar SejaAlpha.apk
  1. Baixe o arquivo no celular e toque nele.
  2. O Android vai avisar que o arquivo não veio da Play Store e pedir para permitir instalar apps desconhecidos. Autorize — é normal para app de uso interno.
  3. Toque em Instalar.
E no iPhone? Não existe arquivo para instalar no iPhone, e não é escolha nossa: a Apple só permite instalar app pela App Store, o que exige conta paga de desenvolvedor e revisão a cada versão. APK é formato exclusivo do Android — o iPhone não abre esse arquivo. Para iPhone o caminho é o de cima, pelo Safari: fica com ícone na tela de início e abre em tela cheia igual a um app de loja.

Banco de dados do Seja Alpha

O banco é SQLite (um arquivo só: whatsapp.db), guardado no servidor. Para abrir e editar à mão, use estes dois programas gratuitos.

DB Browser WinSCP
  1. DB Browser for SQLite — abre o banco em tela, mostra as tabelas e deixa editar linha a linha ou rodar SQL. O instalador está hospedado aqui; a versão oficial fica em sqlitebrowser.org.
  2. WinSCP — copia o arquivo do servidor pro seu computador e devolve depois (conecta em 46.202.151.252, usuário root, com a chave SSH).
  3. O arquivo fica em /opt/whatts-inbox/backend/data/whatsapp.db.
Antes de editar, faça nesta ordem: 1) gere um backup pelo próprio sistema (Configurações → Backup); 2) pare o serviço no servidor (systemctl stop whatts-inbox) — editar com o sistema rodando pode corromper o banco e derrubar o atendimento; 3) edite; 4) suba o arquivo de volta e ligue (systemctl start whatts-inbox). Para só consultar sem alterar nada, pode abrir uma cópia com o sistema no ar.
